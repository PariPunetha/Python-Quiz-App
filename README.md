# 🧠 Python Quiz App

A command-line Quiz Application built with Python. Test your Python knowledge by answering multiple-choice questions and receive your score, percentage, and performance feedback at the end.

## ✨ Features

- 📝 Multiple-choice quiz
- ✅ Instant correct/wrong answer checking
- 📊 Final score calculation
- 📈 Percentage calculation
- 🏆 Performance feedback
- ⏳️ time tracking 
- 🔁 Play Again option

## 🛠️ Technologies Used

- Python 3

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the Python file.

```bash
python Quiz_App.py
```
